# STEP Week 10: Coding Practice Set

My solutions to the Week 10 practice problems of the **STEP Java Programming** track.

## Topics covered

- String processing
- Loops and arrays
- Two-pointer reversal
- Digit arithmetic
- Prime numbers and factorials
- Grading and leap-year logic
- Classes and constructors

## How to run

You need JDK 8 or later.

```bash
cd Practice
javac FileName.java
java FileName
```

Replace `FileName` with the program name. Programs marked **Interactive** read input from the terminal; the rest run a built-in example straight away. Each file is self-contained, so you can also open it in VS Code or IntelliJ and press **Run**.
